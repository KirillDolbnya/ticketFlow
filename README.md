# TicketFlow API

**TicketFlow API** — это специализированный бэкенд-сервис для платформ онлайн-бронирования, автоматизирующий полный цикл продажи билетов и управления событиями.

### Концепция и назначение сервиса:
* **Для администраторов**: предоставляет программный интерфейс для конструирования залов любой конфигурации (разметка секторов, рядов и посадочных мест), а также гибкого создания и модерации целевых мероприятий.
* **Для пользователей**: обеспечивает логику поиска актуальных событий, проверку доступности свободных мест на схеме зала в реальном времени и гарантированную обработку запросов на покупку или бронирование билетов.

> **Note**  
> Это самостоятельный учебный (pet) проект, разработанный с целью проектирования чистой архитектуры бэкенда, отработки навыков работы с высоконагруженными операциями (избежание race conditions при бронировании) и создания гибкого RESTful API.


### 1. Подготовка окружения
Создайте файл `.env` в корневой директории проекта и задайте переменные окружения для подключения к базе данных (они автоматически подставятся в конфигурацию PostgreSQL):

```bash
cp .env.example .env
```

### 2. Сборка и запуск контейнеров
Запустите сборку Docker-образов и старт всех сервисов (Nginx, PHP-FPM, PostgreSQL) в фоновом режиме:

```bash
docker compose up -d --build
```

### 3. Установка зависимостей (Composer)

```bash
docker compose exec app composer install
```

---

### 4. Генерация ключа приложения (Laravel)
Сгенерируйте ключ шифрования приложения:

```bash
docker compose exec app php artisan key:generate
```

---

### 5. Запуск миграций базы данных
Запустите миграции для создания структуры таблиц в PostgreSQL:

```bash
docker compose exec app php artisan migrate
```

---

### 6. Проверка доступности

*`http://localhost:8080/up`.*

---

## Запуск тестов

```bash
docker compose exec app php artisan test
```

---

## Остановка проекта

Чтобы остановить работу всех контейнеров без удаления данных из базы данных:
```bash
docker compose down
```

---

Если вам нужно полностью очистить окружение, включая созданный volume базы данных `postgres_data`:
```bash
docker compose down -v
```
